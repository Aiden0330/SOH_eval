项目概览

系统以可比较、可追溯、可复核的算法测评为第一目标，并以跨数据集、跨电芯和跨化学体系的多场景算法建设为第二目标。

  • 当前已实现：本机资源目录、训练与推理任务、结果发布和证据基础。
  • 已接入领域能力：Battery SOH 曲线、特征、算法和完整看板。
  • 目标架构：隔离 Worker、前端 V2 和更强的外部插件治理。

总体架构与数据流

当前代码提供本机控制面、训练与推理执行、结果发布和证据对象；隔离 Worker 属于目标架构。

SOH 数据、特征与算法原理

领域能力围绕 SOH 标签、充电曲线、IC/DVA、健康指标和多类回归估计器组织。

公平测评协议与指标

公平比较必须锁定数据快照、协议、随机种子、留出覆盖和统计单位。

核心契约与证据对象

RunSpec、DatasetSnapshot、PredictionRecord 和 EvidencePack 共同形成可复核证据链。

前端五页签功能说明

训练测评、推理测评、模型资产库、SOH 完整看板和全局诊断承担不同职责。

工具安装、启动与配置

前端通过静态 HTTP 服务加载，后端 API 默认连接本机 Battery SOH 数据目录。

新资源接入

数据集、算法、特征方案和冻结模型均先验证，成功后再事务性激活。

训练测评与冻结推理

训练页负责产生模型；推理页负责验证已有模型在新数据上的迁移精度和速度。

结果、排行与证据解释

结果文件、质量报告和证据包必须结合覆盖范围、执行结果和验收裁决共同解释。

数据同步与离线打包

同步与打包采用不可变 generation 和 last-known-good 发布语义。

常见问题、安全边界与排障

排障从预检、任务状态、特征兼容性、前端缓存和结构化失败信息逐层定位。
