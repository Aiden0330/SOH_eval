## H1 — Weighted conformal (`conformal.py`)

`WeightedConformalWrapper(base, alpha=0.1, calib_frac=0.2)`:
- `fit(X,y,meta)`: split train **tail** as calibration (as in `ConformalWrapper`); fit base on the rest; store calib **abs residuals** AND calib **feature matrix**.
- `predict_interval(X_test,meta,alpha=None)`: fit `sklearn.linear_model.LogisticRegression` on `[calib_features → 0, test_features → 1]`; importance weight per calib point `w_i = p1/(1-p1)` (density ratio, clipped to a sane max e.g. 1e3); normalize weights; take the **weighted quantile** of calib residuals at level `1-alpha` → `q_w`; interval `pred ± q_w`. `ci_source = "weighted_conformal"`.
- Falls back to the unweighted quantile if the classifier degenerates (one class, or <5 calib points).

Runner integration: protocols gain a boolean `cross_domain` attribute (`LeaveOneCellOut`=False; `LeaveOneDatasetOut`/`LeaveOneChemistryOut`/`ForwardChaining`=True). In the runner, for estimators **without** native intervals: wrap with `WeightedConformalWrapper` when `protocol.cross_domain` else `ConformalWrapper`. `ci_source` recorded accordingly (`weighted_conformal` / `conformal` / `native`).

## H2 — BYO feature-mode track (`runner.py`, `report.py`, a demo estimator)

- Runner: read `feature_mode` from each estimator instance. If `feature_mode == "byo"`, **do not project** to the active featureset — pass the full (already feature-set-`full`) table so the estimator self-selects; tag records `track="byo"`, `featureset="(byo)"`. Otherwise `track="unified"`, project as today. Record `track` per estimator (stop relying on the CLI's global `feature_mode="unified"`).
- Report: group leaderboard by `track` too; entries already carry `track`. Unified-track and byo-track entries must never be ranked together (separate sections / clearly labeled).
- Demo estimator `src/sohbench/estimators/byo.py`: `ByoSelectKBestRidge` (`name="byo_skb_ridge"`, `feature_mode="byo"`, `backend="sklearn"`): `SelectKBest(f_regression, k=min(6, n_features))` → StandardScaler → Ridge; clamp `[0,1.3]`. Demonstrates self-selection; on `full` it should roughly match or beat plain ridge.

## H5 — Chemistry-out per-chemistry folds (`protocols.py`)

Replace wholesale downgrade with: generate one fold per chemistry (hold out all that chemistry's rows). For a held-out chemistry whose data spans `< 2` datasets, set `Fold.held_out_key = f"{chem} (confounded: 1 dataset)"` and emit a `warnings.warn` naming it; chemistries with `>= 2` datasets are unflagged genuine folds. If **only one chemistry** is present overall, skip with a warning (can't hold one out). Tests: with nasa(LCO)+calce(LCO)+hust(LFP)+oxford(LCO/NCO), expect 3 folds (LCO, LFP, LCO/NCO); the LCO fold is unflagged (2 datasets), LFP and LCO/NCO flagged confounded.
