## 5. 发现的问题

### 5.1 `full` 特征模型推理兼容性失败

第一次验收使用 `nasa + ridge + full + loco + seed 0` 训练：

| 字段 | 结果 |
|---|---|
| 训练任务 | `20260630T105254-70934b72` |
| 状态 | `succeeded` |
| 运行目录 | `runs\20260630T105307` |
| 产出 Pickle 数 | `32` |

但用 `ridge_full_loco_nasa_B0005_seed0` 推理 `nasa` 和 `calce_cs2` 时，推理任务 `20260630T105326-c055b476` 失败，错误为：

```text
missing feature columns for ridge_full_loco_nasa_B0005_seed0: ['ambient_temp_c']
```

原因判断：训练阶段的 `full` manifest 包含 `ambient_temp_c`，但推理阶段加载的数据表不包含该列。该问题说明模型 manifest 与目标数据集 schema 的兼容性校验是有效的，但前端需要更明确提示用户选择兼容特征集或重新生成模型。

前端推理页已增加“兼容性预检”区域，使用模型 manifest 中的 `feature_columns` 与后端数据集 catalog 中的 `columns` 做前端侧集合差集检查。

- 页面无横向溢出。

结论：前端已能在启动 inference-only 任务前暴露模型与目标数据集的特征列兼容性风险。后端仍会在运行时执行最终校验。

### 5.4 推理启动策略开关已接入

前端推理页已增加启动策略分段控件：

- `仅运行兼容组合`：默认策略。提交后端前会剔除对已选模型存在 `warn` 或 `unknown` schema 风险的数据集。
- `包含风险组合`：按当前勾选提交，交由后端运行时校验。

浏览器复验：

- 默认策略为 `仅运行兼容组合`。
- 当前选择下策略提示为：`6 个数据集将提交；已跳过 1 个存在 schema 风险的数据集：rwth_isea_public`。
- 切换到 `包含风险组合` 后，提示更新为：`将按当前勾选提交，后端运行时校验不兼容组合。`
- 策略按钮可见、可点击，页面无横向溢出。

结论：用户可以在保守自动过滤和显式包含风险之间切换，避免一键推理被已知不兼容数据集拖失败。

### 5.5 推理策略审计字段已落盘

前端启动推理任务时会随请求提交 `launch_strategy`、`selected_datasets`、`submitted_datasets` 和 `skipped_datasets`。后端创建 inference-only 任务后会保留这些字段，并在任务完成后写入 `inference_run_config.json`。

代码级复验：

- `compatible_only` 会记录用户原始选择、实际提交数据集和被跳过数据集。
- `include_risk` 会记录按当前勾选提交，`skipped_datasets` 为空。
- 后端任务 `request` 与落盘配置文件中的审计字段一致。

结论：推理任务现在可以追溯本轮使用的是保守过滤策略还是包含风险策略，也能复盘哪些数据集被过滤。

### 5.6 前端审计追踪已接入

前端现在会加载 `inference_run_config.json`，并在后端可用时优先使用 `/api/catalog` 中最近的 `inference_jobs` 记录。推理页的“迁移分析”区域会展示策略、选择/提交数据集数、跳过数据集和 run 目录；模型资产页摘要也会展示最近一次推理策略。

代码级复验：

- 静态运行配置可生成中文审计摘要。
- 后端任务记录优先级高于静态配置，适合在线模式查看最新任务。
- 模型资产摘要不会再只展示精度和速度，也能追踪最近推理任务的策略上下文。

结论：审计信息已经从后端落盘推进到前端可见，后续排查迁移测评时可以直接从界面看到过滤策略和跳过数据集。

### 5.7 任务历史抽屉已接入

前端新增“任务历史”入口，复用后端 `/api/catalog` 中的 `jobs` 与 `inference_jobs`，统一展示训练和推理任务。抽屉支持按任务类型、状态、推理策略和数据集名称过滤，任务卡片展示任务 ID、资源摘要、策略、数据集范围和 run 目录。

代码级复验：

- 训练任务和推理任务会被归一化成统一历史行。
- 推理任务可按 `compatible_only`、`include_risk`、`unspecified` 过滤。
- 数据集搜索会匹配原始选择、实际提交和跳过数据集。
- 抽屉固定在页面右侧，列表内部滚动，不增加主工作台高度。

结论：任务追踪已经从“最近一次审计”扩展为可筛选历史视图，适合排查多轮训练/推理测评。
